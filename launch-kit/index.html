Architecture

Six layers,
zero surprises.

Every tool call flows through the same pipe. No hidden network, no implicit writes, no silent overwrites.

request lifecyclestdio JSON-RPC · no network
  1. 01Security bootstrap — security/bootstrap.ts

    First import evaluates the CVE-2026-111497 hard-lock (node:zlib Brotli APIs replaced with throwing stubs) and checks your Node/Bun version against the patched releases.

  2. 02MCP handlers — index.ts

    10 tools, 2 resources, 1 prompt. Pure stdio transport; tool failures return isError: true, never a protocol crash.

  3. 03Input validation — validation.ts

    Types, ranges, positive IDs and hard size limits on every argument. The MCP SDK doesn't enforce schemas — so this does, always.

  4. 04Secret redaction — security/secretRedactor.ts

    Pattern-based masking (OpenAI / GitHub / AWS / Slack / Google / JWT / PEM) on every write path — memories, handoffs, preferences.

  5. 05Storage — db/memoryStore.ts

    Embedded SQLite (WAL) + FTS5 BM25 at ~/.mindgate/mindgate.db — owner-only permissions (chmod 600, dir 700). Triggers keep the index in sync.

  6. 06Rules writer — rulesSync.ts

    Compiles memory into AGENTS.md-class files: atomic temp+rename, .bak-<timestamp> backups, sentinel marker guards your hand-written files.

⚠️ Honest limits: memories are data, not instructions · redaction is best-effort pattern matching · the Brotli lock is defense-in-depth — a patched runtime is the definitive fix. Full threat model in SECURITY.md.

FAQ

Fair questions.
Straight answers.

Does my code or memory leave my machine?

No. MindGate has no network code at all — it speaks stdio JSON-RPC to your agent and SQLite to your disk. The only way data leaves is if you paste it into an agent that sends it to a model API, same as always.

What happens if I paste an API key into a memory?

Known token shapes (OpenAI, GitHub, AWS, Slack, Google, JWT, PEM) are replaced with [REDACTED:kind] before anything is written, and the tool response tells you how many were caught. It's a strong safety net, not a guarantee — keep secrets out of prompts entirely.

Will sync_workspace_rules overwrite my hand-written AGENTS.md?

Never silently. MindGate-generated files carry an HTML sentinel marker; hand-written files are refused unless you explicitly pass force: true — and a timestamped .bak backup is always created first. Writes are atomic (temp file + rename).

Which agents work with it?

Anything that speaks MCP over stdio with tool support: Antigravity, Cursor, Claude Desktop, OpenCode, Codex CLI, Windsurf, Cline. If it launches an MCP server, MindGate plugs in.

How do I uninstall?

Remove the MCP server entry from your client config, then delete ~/.mindgate/. That's it — one directory, one config block. No daemon, no registry, no residue.
